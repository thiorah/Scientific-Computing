# BIT 2118 – Scientific Computing

## About This Repository
This repository contains my individual Python implementations of the Scientific Computing coursework for BIT 2118.

The project explores numerical methods and their applications in scientific, engineering, mathematical and computing problems.

## Technologies Used
- Python
- NumPy
- SciPy
- Matplotlib
- VS Code

## Topics Covered
The repository contains practical implementations of:

- Numerical computation and Python programming
- Linear algebra and matrix operations
- Numerical methods for solving equations
- Interpolation and curve fitting
- Numerical differentiation and integration
- Ordinary differential equations
- Numerical optimization
- Random numbers and Monte Carlo simulation

## Installation and Setup

Clone the repository:

```bash
git clone https://github.com/thiorah/BIT2118-Scientific-Computing.git
```

Navigate into the project:

```bash
cd BIT2118-Scientific-Computing
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run an individual task:

```bash
python task_17/task_17.py
```

Change the task folder and script name when running other exercises.
